1. Sign in to NotebookLM / Gemini Notebook using an eligible account.
2. Create one notebook: `Stay Smart in the Digital World — Learning Lab`.
3. Upload the four local source files separately; check correct extraction from DOCX and PPTX (important: verify actual text visible in Notebook).
4. Add the FTC webpage as a website source; inspect imported text and citation.
5. Add CISA's public YouTube URL. Verify that an accessible transcript is imported. If the import fails, use the alternative candidate video or omit the video source; never claim six sources are active unless they all imported.
6. Check that all imported sources are selectable and correctly named. Ask one factual question per source, then one cross-source question.
7. Generate/check a mind map, quiz, flashcards, infographic, slide deck, report, Audio Overview and Video Overview according to account availability. Studio generation may take time and output quality may vary.
8. Inspect all citations, typography and media before presenting. Keep a locally saved excerpt or screenshot only where export and sharing rights allow it.
9. Prepare a tab with the official FTC article open for verification.
10. Use the source map and demo prompt file for consistent demonstrations.
