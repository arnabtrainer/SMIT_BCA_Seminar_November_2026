# 📚 AI in Action — Complete Glossary

**Workshop series:** Learn • Create • Build  
**Purpose:** A beginner-friendly reference to essential terms used across all five modules.  
**Audience:** Students, educators, researchers, professionals and curious learners.

> **Note:** Some terms refer to AI capabilities; others refer to specific applications or production methods. Product interfaces and availability can change over time.

## 🤖 Module 1 — Discover the Power of AI

| Term | Meaning |
|---|---|
| **Artificial Intelligence (AI)** | Technology that enables computers to perform tasks associated with human intelligence, such as recognising patterns, understanding language or making predictions. |
| **Algorithm** | A clear, ordered set of steps used to solve a problem or complete a task. |
| **Machine Learning (ML)** | A way to build AI systems that learn patterns from examples rather than relying only on explicitly written rules. |
| **Generative AI** | AI that creates new content, such as text, images, audio, video or code, in response to instructions. |
| **ChatGPT** | An AI assistant that can respond to prompts, explain concepts and help create text, images and other outputs depending on available features. |
| **AI Model** | A trained computational system that takes input and produces results such as predictions, explanations or generated content. |
| **Large Language Model (LLM)** | A type of AI model trained on large collections of text and other data to process and generate language. |
| **Training Data** | Examples used when developing a model so it can learn useful patterns. |
| **Prompt** | The question, instruction or information given to an AI system to request a response. |
| **Prompt Engineering** | The practice of improving prompts by specifying the task, context, constraints and desired output. |
| **Context** | Background information that helps an AI system understand what the user wants and respond appropriately. |
| **Natural Language Processing (NLP)** | Technology that enables computers to analyse, interpret and generate human language. |
| **Multimodal AI** | AI that can work with more than one kind of information, such as text, images, speech or video. |
| **AI Hallucination** | A plausible-sounding AI response that includes invented, incorrect or unsupported information. |
| **Responsible AI** | Using AI with attention to accuracy, fairness, privacy, transparency, permissions and human oversight. |

## 📚 Module 2 — AI Can Help Me Learn

| Term | Meaning |
|---|---|
| **Gemini Notebook** | Google’s source-based AI notebook for exploring uploaded materials and creating learning resources; previously known as NotebookLM. |
| **Source** | An original document, webpage, video transcript or other item supplied as reference material. |
| **Source Import** | Adding material such as a PDF, document, presentation, webpage or eligible YouTube video to a notebook. |
| **Source-Grounded Q&A** | Asking questions whose answers are based on the sources selected within a notebook. |
| **Citation** | A reference that identifies the source passage supporting an answer or statement. |
| **Source Summary** | A shorter account of the most important information in one or more reference materials. |
| **Mind Map** | A visual diagram showing a central topic and its connected ideas, categories or subtopics. |
| **Quiz** | A set of questions used to practise or check understanding of a topic. |
| **Flashcard** | A two-sided learning card with a question or key term on one side and its answer on the other. |
| **MCQ Question Bank** | A collection of multiple-choice questions with answer choices and usually an answer key. |
| **Audio Overview** | An AI-generated spoken explanation or discussion based on selected source materials. |
| **Video Overview** | An AI-generated narrated visual explanation of information from selected sources. |
| **Infographic** | A visual presentation of facts, steps or comparisons using concise text, charts and illustrations. |
| **Slide Deck** | A sequence of presentation slides used to explain and communicate information. |
| **Report** | A structured written output that organises findings, explanations, summaries or recommendations. |
| **Source Verification** | Checking an AI-produced statement against the original source and, when necessary, other trustworthy evidence. |

## 🎬 Module 3 — AI Can Help Me Create

| Term | Meaning |
|---|---|
| **Creative Brief** | A short description of the product, audience, communication goal, central message, style and deliverables for a project. |
| **Storyboard** | A sequence of visual plans or frames showing how a video’s story will unfold. |
| **Scene** | A section of a film taking place within a particular setting or part of the story. |
| **Shot** | A continuous view from one camera perspective before a cut to another view. |
| **Scene-Wise JSON Prompt** | A structured description of each scene’s subject, action, setting, camera, lighting and constraints, stored in JSON form. |
| **Reference Image** | An image provided to guide the appearance, composition or style of generated footage. |
| **Visual Continuity** | Keeping products, characters, clothing, scenery, lighting and style consistent across shots. |
| **Text-to-Image** | Generating a new image from a written description. |
| **Image-to-Video** | Creating moving footage by animating or extending a supplied still image. |
| **Text-to-Video** | Generating moving video footage directly from a written description. |
| **Google Vids** | Google’s online video creation and editing application, with AI features available to eligible accounts. |
| **Veo** | Google’s family of generative video models used in supported video-creation workflows. |
| **Camera Movement** | The way a virtual camera moves during a shot, such as panning, tracking or slowly moving closer. |
| **Cinematography** | The visual craft of choosing framing, movement, lighting, lenses and composition to tell a story. |
| **Colour Grading** | Adjusting the colours, contrast and overall visual tone to create a consistent look. |
| **Aspect Ratio** | The width-to-height proportion of an image or video; 16:9 is a common landscape format. |
| **Narration / Voiceover** | Spoken words heard over a video to explain, guide or emotionally support the visual story. |
| **MiniMax Speech** | A speech-generation tool that can create AI voiceovers from narration scripts. |
| **MiniMax Music** | A music-generation tool that can create background soundtracks from style instructions. |
| **Text-to-Speech (TTS)** | Technology that converts written text into synthesised spoken audio. |
| **Background Music** | Music used underneath the video to establish mood and support the story. |
| **Sound Effects (SFX)** | Sounds that reinforce on-screen actions or environments, such as footsteps, pouring water or wind. |
| **Audio Mixing** | Balancing narration, music and sound effects so that each is clearly heard at the appropriate level. |
| **Video Timeline** | An editor’s arrangement of video and audio clips in their playback order. |
| **Transition** | A method of moving between shots, such as a cut, fade or dissolve. |
| **Call to Action (CTA)** | A short invitation asking viewers to take a next step, such as learning more or visiting a website. |
| **Video Export** | Saving an edited video into a shareable format, commonly an MP4 file. |

## 🛠️ Module 4 — AI Can Help Me Build

| Term | Meaning |
|---|---|
| **AI-Assisted Application Development** | Using an AI assistant to help plan, generate, explain, test or improve software. |
| **Natural-Language Programming** | Describing desired software behaviour in ordinary language so an AI tool can assist with implementation. |
| **Claude** | An AI assistant that can help create, explain and refine content and interactive applications. |
| **Claude Artifact** | A shareable interactive output created in Claude, such as a small web application, visualisation or tool. |
| **Prototype** | An early working version of a product built to demonstrate or test an idea. |
| **No-Code Development** | Building applications mainly through visual or natural-language tools instead of manually writing all the code. |
| **User Interface (UI)** | The screens, buttons, menus, forms and other visible parts through which a person uses an application. |
| **User Experience (UX)** | How understandable, useful and comfortable an application feels to the person using it. |
| **Responsive Design** | An interface that adjusts to different screen sizes, such as phones, tablets and laptops. |
| **Task Management** | Organising activities by recording what must be done, assigning priorities and tracking completion. |
| **Priority** | A label showing the relative importance or urgency of a task. |
| **Deadline** | The date or time by which an activity should be completed. |
| **Progress Tracker** | A visual or numerical indicator showing how much of a set of activities has been completed. |
| **CRUD Operations** | The four common data actions in an application: Create, Read, Update and Delete. |
| **Input Validation** | Checking information entered by users to prevent missing, incorrect or unsafe values. |
| **Software Testing** | Checking that an application’s features work correctly, including unusual and invalid inputs. |
| **Bug** | A defect in software that causes unexpected or incorrect behaviour. |
| **Iteration** | Improving a product through repeated cycles of changes, testing and feedback. |
| **Local Storage** | A way for a web application to save information within the user’s browser on their device. |
| **Offline-First Application** | An application designed to remain useful even when an internet connection is unavailable. |
| **Data Export** | Saving application information to a portable file, such as CSV or JSON. |

## 🚀 Module 5 — Your AI Journey Starts Here

| Term | Meaning |
|---|---|
| **Learning Outcome** | A skill or understanding that participants are expected to gain from an activity or programme. |
| **Knowledge Check** | A short activity that helps participants assess what they have understood. |
| **Multiple-Choice Question (MCQ)** | A question offering several possible answers, usually with one best answer. |
| **Distractor** | An incorrect but plausible answer option designed to test careful understanding. |
| **Answer Key** | A list of the correct responses to quiz or assessment questions. |
| **Google Forms** | An online tool for creating quizzes, feedback surveys and collecting responses. |
| **Feedback Form** | A questionnaire used to collect participants’ opinions and suggestions. |
| **Rating Scale** | A set of response values, such as 1 to 5, used to express a level of satisfaction or confidence. |
| **QR Code** | A scannable square code that can open a webpage, form or other digital resource. |
| **Learning Reflection** | Thinking about what was learned, what remains unclear and what to explore next. |

---

### ✅ Essential Reminder

AI can help us **understand information, create content and build applications**, but people remain responsible for checking accuracy, testing outputs, protecting private information and respecting the rights of others.
