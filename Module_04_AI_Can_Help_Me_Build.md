# Module 4 — AI Can Help Me Build

**Primary tool:** Claude Artifacts (using a tested account and supported build workflow)  
**Seminar:** AI with Applications — Learn, Create & Build Your Future  
**Target time:** 20 minutes  
**Priority:** Flexible — live build only when time allows

## Purpose
Show students that they can describe a small useful software application in everyday language, test the output and request a refinement, without having to know programming syntax in advance.

## One shared project
**“My Smart Study Planner”** — students enter subjects and available study time; the app proposes a simple schedule and tracks completed sessions. Use local sample data, no account sign-in or external API, and no sensitive personal information.

## Learning outcomes
- Describe a real-life problem in user-friendly terms.
- Recognise the basic parts of an application: input, processing, output and testing.
- Experience natural-language application creation and revision.
- Learn that a working-looking app still requires validation.

## Full live flow (20 minutes)
1. **0–4 min — Need:** “How can I balance study time across four subjects?”
2. **4–9 min — Build:** Show a prepared prompt and generate or open a working Artifact.
3. **9–14 min — Test:** Change subjects and hours; mark one task complete; inspect the result.
4. **14–18 min — Improve:** Ask AI to add a progress indicator or change a misleading schedule.
5. **18–20 min — Takeaway:** Explain that students can learn the underlying code over the BCA course.

## 5-minute fallback (mandatory)
If running late, **open the tested, prebuilt study planner**, invite one student to choose subjects/hours, click through the output, and explain that AI helped create it. Do not initiate a live generation. This retains the “Build” message without delaying the quiz or feedback.

## Optional extension (+15–20 minutes, only if college agrees)
Run a complete generation from a fresh prompt, explain two functions, and test several edge cases with the students. Never assume the extension is available.

## Preparation
- Tested prebuilt planner accessible without a long login sequence.
- Offline screenshots or screen recording of the working app.
- One prompt for initial build and one short improvement prompt.
- Sample subjects and times appropriate for brand-new students.

## Trainer reminder
The purpose is to spark confidence and curiosity—not to imply that software engineering, debugging or security are unnecessary.
