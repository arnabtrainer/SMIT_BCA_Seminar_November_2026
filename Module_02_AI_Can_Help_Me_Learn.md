# Module 2 — AI Can Help Me Learn

**Primary tool:** Gemini Notebook (formerly Google NotebookLM)  
**Seminar:** AI with Applications — Learn, Create & Build Your Future  
**Target time:** 40 minutes  
**Priority:** Essential

## Purpose
Show how an ordinary introductory learning resource can become a conversational tutor, visual study guide, quiz, and audio learning companion. Keep the example approachable for prospective and first-year BCA students.

## One shared project
**“My First BCA Learning Companion”** — a small, trainer-prepared PDF on **What is Computer Science? Introduction to Computers, Applications, and Career Possibilities**. Use fictional scenarios and verify any real institutional or employment claims separately. Avoid advanced SQL or machine-learning formulas.

## Learning outcomes
- Add learning material to a source-grounded notebook.
- Ask clear questions and check source citations.
- Create a study summary and short quiz.
- Experience a mind map and a short audio overview.
- Understand why a generated answer should still be checked against the uploaded material.

## Proposed live flow (40 minutes)
1. **0–5 min — The problem:** A new student receives pages of notes but is uncertain where to begin.
2. **5–12 min — Create a notebook:** Upload a short introductory PDF and ask basic questions such as “What is a programming language?” and “How is BCA relevant to daily technology?”
3. **12–19 min — Make learning easier:** Ask for beginner-friendly explanations, a glossary, and a one-week learning roadmap.
4. **19–25 min — Source verification:** Open a citation and find the supporting passage. Ask a question whose answer is absent and discuss what the tool does.
5. **25–32 min — Interactive revision:** Show a mind map and generate five simple MCQs. Invite answers from the audience.
6. **32–37 min — Audio surprise:** Play an excerpt of a **pre-generated** overview in English or Bengali, if available on the account.
7. **37–40 min — Recap:** Ask students how they could use the approach with their own class notes.

## Materials
- A tested sample PDF (2–3 pages; trainer-written, not confidential).
- An already-created notebook with working citations, mind map, quiz and audio sample.
- Screenshots and an offline audio file or screen recording as backup.

## Participation
Let students propose one question, vote on one MCQ, and spot a claim that needs checking.

## Shortening / extension
- **Short version (30–35 min):** Show only one question, one citation, one quiz and pre-generated audio.
- **Extended version (45 min):** Include student-led follow-up questions and a second learning format.

## Trainer reminder
Do not present the generated quiz as a prediction of real examination questions. Use the current product name **Gemini Notebook**, while acknowledging that many students know it as **NotebookLM**.
