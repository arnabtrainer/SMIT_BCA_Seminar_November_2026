## 📋 Copy-ready live prompts

**1. Summary**
```text
Based on the selected sources, explain the most important digital safety habits under four headings: Recognise, Protect, Verify and Respond. Give six concise takeaways and identify the source supporting each. Clearly label fictional case examples.
```

**2. Grounded Q&A and evidence**
```text
According to the Digital Safety Fundamentals PDF and the FTC webpage, what should someone do after receiving an unexpected account-verification link? Explain the safe response step by step, cite supporting passages, and state any uncertainty or missing information.
```

**3. MCQ bank — optional advanced output**
```text
Create 8 beginner-friendly multiple-choice questions based only on selected sources. For each, provide options A–D, one best answer, a brief explanation, and supporting source citation. Clearly identify fictional scenarios; provide an answer key.
```

**4. Glossary — optional advanced output**
```text
Produce an alphabetical glossary of 12 digital-safety terms found in the selected sources. Give one simple definition, a short everyday example, and a supporting citation for each. Omit terms not supported by the sources.
```

## 🎛️ Eight Studio outputs — exact actions and tailored prompts

**Important:** Once the sources are imported, Gemini Notebook can generate Studio artifacts using default settings. A **custom prompt is optional, not compulsory**, for most output types, but is strongly recommended when you want a particular audience, focus, style or difficulty. This is your private copy-and-paste prompt bank; these prompts are **not shown on audience slides**. In the Studio panel, use the relevant artifact tile or its **customize / pencil** control (where offered). Interface details can vary by account and updates.

### 1. 🧠 Mind Map — default generation (no dedicated prompt necessary)
**Action:** Select relevant sources, then choose **Mind Map** in the chat (or its available Studio entry point). Open the resulting map in Studio. Expand **Online Threats**, **Prevention**, and **Response**, if these branches appear. Click a node to ask a cited follow-up question. The branch labels are AI-generated and may differ.

**Optional preparation query in Chat (NOT the Mind Map generator):**
```text
Using the selected sources, identify the major categories of digital safety under four headings: Recognise, Protect, Verify, and Respond. Explain the relationships briefly and distinguish fictional case examples from published guidance.
```

### 2. 📝 Quiz — customized Studio quiz
**Action:** Studio → **Quiz** → customize (pencil) if available; select **beginner**, English, and an appropriate number of questions.

**Custom instruction:**
```text
Build an interactive beginner-friendly digital safety quiz based only on the selected sources. Focus on recognising suspicious messages, verifying sender identities, MFA, protecting personal data, and safe incident response. Prefer realistic decisions from the fictional case studies but label them as fictional. Include clear explanations after answers; avoid unsupported statistics and trick questions.
```

### 3. 🗂️ Flashcards — customized Studio flashcards
**Action:** Studio → **Flashcards** → customize (pencil); choose beginner difficulty and a small deck.

**Custom instruction:**
```text
Create concise revision flashcards about 12 important digital safety concepts supported by the selected sources. Put one clear question or term on the front and a simple definition or safe practice on the back. Include phishing, MFA, passkeys, verification, privacy, QR-code risks, and reporting only when supported. Prefer memorable examples without presenting fictional scenarios as real incidents.
```

### 4. 🎧 Audio Overview — customized Studio audio
**Action:** Studio → **Audio Overview** → choose **The Brief** for a short one-voice explanation, or **Deep Dive** for a conversation; choose language and length as available. Paste prompt below into the optional focus field.

**Custom instruction:**
```text
Create an engaging, accessible audio overview for an audience new to digital safety. Explain how to recognise suspicious links and messages, why independent verification matters, and three everyday habits that reduce risk. Bring one clearly identified fictional case to life, without claiming it happened in reality. Base the explanation only on the uploaded sources, avoid sensationalism, and end with one practical takeaway.
```

### 5. 🎬 Video Overview — customized Studio video
**Action:** Studio → **Video Overview** → choose **Short** if available (otherwise **Explainer**); select supported narration language, visual style, and custom focus, then generate **in advance**.

**Custom / steering prompt:**
```text
Create a visually clear introductory educational video titled 'Stay Smart in the Digital World'. Using the selected sources, show: (1) a suspicious message, (2) a pause to check authenticity through an independent channel, (3) how MFA adds protection, and (4) safe next steps when a scam is suspected. Use generic illustrations, simple language, and explicitly fictional examples. Do not invent facts, statistics, brand endorsements, or real victims.
```

### 6. 🎨 Infographic — customized Studio visual
**Action:** Studio → **Infographic** → customize → choose **Portrait** or **Landscape** and **Professional** visual style if available.

**Custom instruction:**
```text
Create a modern, easy-to-read infographic with the heading 'Pause • Check • Protect'. Divide it into three visual sections: warning signs of a suspicious message, independent verification, and safer account habits. Use a restrained navy–teal–orange palette, large legible headings, simple icons, short accurate statements, and no unsupported statistics. Use only facts supported by the selected sources; mark hypothetical examples as examples.
```

### 7. 📊 Slide Deck — customized Studio presentation
**Action:** Studio → **Slide Deck** → customize → choose **Presenter Slides** or other concise format where available, output language and length. Paste instruction below.

**Custom instruction:**
```text
Create an engaging short presentation called 'Digital Safety: Everyday Decisions That Matter'. Target non-specialists of mixed academic and professional backgrounds. Use a clean 16:9 visual style, short headings, diagrams and relatable scenarios. Cover why digital safety matters, signs of phishing, verification habits, account protection, one explicitly fictional scenario and key takeaways. Keep factual claims grounded in the selected sources; do not invent institutional branding or statistics. Avoid excessive text per slide.
```

### 8. 📑 Report — customized Studio document
**Action:** Studio → **Reports** → **Document** → select a **Briefing Document** template (or another relevant template) → **Edit / customize**.

**Custom instruction:**
```text
Prepare a concise, evidence-based 'Digital Safety Awareness Briefing' for a general audience. Use sections: Executive Summary, Common Threats, Warning Signs, Prevention Checklist, What to Do After a Suspicious Message, Fictional Learning Cases, and References. Differentiate guidance in the FTC/CISA sources from invented teaching scenarios, and cite source passages for specific recommendations. State where the uploaded materials do not substantiate a claim.
```

**Review all eight outputs:** verify factual accuracy, citation fidelity where available, visual text, spelling, images and audio narration. The output may not follow every requested instruction exactly. Long-running generation should be completed before the session; no real account data is required.
